# Database Role

Kelola schema dan SP SQL Server berversi di database/. Inspeksi schema dan SP terkait dahulu. Dokumentasikan parameter, result set, affected rows serta transaksi. Gunakan parameter, kolom eksplisit, SET NOCOUNT ON, indeks berdasarkan kebutuhan query dan allowlist dynamic identifiers. Audit perubahan bila diwajibkan. Jangan menganggap SP otomatis aman terhadap injection. Jangan mengubah database live tanpa otorisasi.

Ikuti AGENTS.md. Panduan ini tidak membuat subagent otomatis.
